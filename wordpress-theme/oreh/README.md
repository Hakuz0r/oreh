# OREH — тема WordPress

Чистая тема-каталог под WooCommerce. Корзины и оплаты нет — товары нужны
только чтобы клиент сам добавлял позиции через wp-admin, а на сайте они
показываются карточками с кнопкой «Оставить заявку» / «Подробнее».

## Установка

1. Установить и активировать плагин **WooCommerce** (Плагины → Добавить новый).
   При первом запуске мастер настройки WooCommerce можно смело пропустить —
   платежи, доставка и налоги не используются.
2. Загрузить папку `oreh` в `wp-content/themes/` и активировать тему в
   Внешний вид → Темы.
3. `front-page.php` в теме подхватывается автоматически как главная страница —
   отдельно ничего включать в Настройки → Чтение не нужно.
4. Внешний вид → Меню — создать меню, назначить на позицию «Главное меню».
   Если меню не создано, шапка/подвал сами покажут ссылки на
   Оборудование / Почему мы / Контакты (заглушка на якоря).
5. Внешний вид → Настроить → Контакты OREH — задать телефон, email и часы
   работы, которые используются в шапке, подвале и блоке заявки.
6. Товары → Добавить товар — создать позиции (название, фото, галерея,
   цена, краткое описание — карточка на главной, полное описание —
   страница товара, атрибуты товара — таблица характеристик).
7. Настройки → Постоянные ссылки — выбрать «Название записи», чтобы у
   товаров были человеко-читаемые URL.

## Заявки с сайта

Форма в блоке «Контакты» отправляет POST на `admin-post.php` и письмо на
email администратора (Настройки → Общие → Email администратора). Это не
внешняя CRM — просто `wp_mail()`; если нужна интеграция с почтой/CRM,
это отдельная задача.

## Структура

```
oreh/
├── style.css                   — тема + вся базовая CSS (обязателен для WP)
├── functions.php
├── header.php / footer.php
├── index.php                   — обязательный фолбэк-шаблон WP
├── front-page.php              — главная (интро, hero, каталог, «почему мы», контакты)
├── single-product.php          — страница товара (переопределение WooCommerce)
├── archive-product.php         — архив/каталог товаров (переопределение WooCommerce)
├── woocommerce/content-product.php — карточка товара (переопределение WooCommerce)
├── inc/
│   ├── theme-setup.php         — meню, стили/скрипты, авто-WebP для медиатеки
│   ├── customizer.php          — телефон/email/часы работы
│   ├── woocommerce.php         — поддержка Woo, отключение корзины/checkout
│   └── contact-form.php        — обработчик формы заявки
└── assets/
    ├── css/adaptive.css
    ├── js/main.js + modules/   — ES-модули (мобильное меню, галерея)
    └── images/                 — логотипы и фото (jpg/png + webp)
```

## Картинки: WebP и lazy-loading

- Все `<img>` в теме идут с `loading="lazy"` (кроме первого фото в галерее
  товара — оно должно грузиться сразу).
- Логотипы и фоновые/статичные картинки темы (`assets/images/`) уже
  сконвертированы в `.webp` и подключены через `<picture>` с fallback на
  оригинал.
- Для фото, которые клиент будет загружать через Медиатеку (фото товаров),
  включена автоконвертация: WordPress сам генерирует все размеры
  (thumbnail/medium/large) сразу в WebP — см. фильтр
  `image_editor_output_format` в `inc/theme-setup.php`. Это встроенный
  механизм ядра WP (5.8+), без сторонних плагинов.
